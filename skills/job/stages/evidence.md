# 증거

완료 기준마다 실제 값을 남긴다. "통과했다"는 말이 아니라 값이다.

- 로그: `job.py log "<완료 기준>" "<명령>"` 은 명령을 돌려 출력 전체를 파일로 남기고 기준에 붙인다. 화면에는 기록한 한 줄(종료 코드, 로그 파일 경로)만 나오고, 종료 코드가 0 이 아니면 출력 끝 40줄이 붙는다. 출력 전체는 로그 파일에 있다. 출력에 기대값과 실제값이 둘 다 보이게 명령을 짠다.
- `log` 는 명령 전체의 종료 코드 하나만 남긴다. 여러 명령을 이을 때는 중간 실패가 숨지 않게 `set -e` 나 `&&` 로 잇는다.
- 기대는 경로: 그 증거가 기대는 레포 안의 파일과 폴더를 끝에 `--paths <경로>...` 로 적는다(`log`, `evidence`, `tried` 모두). 적으면 뒤에 고친 커밋이 생겨도 그 경로가 바뀌지 않는 동안 유효하다. 적지 않으면 찍은 커밋에서만 유효해 고칠 때마다 다시 남겨야 한다. 그 기준의 동작을 정하는 파일을 빠짐없이 적는다. 빠뜨린 파일이 바뀌면 검증하지 않은 코드가 병합된다. 경로는 커밋한 뒤에 적을 수 있다.
- 고친 뒤에는 `job.py check` 가 낡았다고 알리는 증거만 다시 남긴다. 같은 기준의 같은 명령(`evidence` 는 같은 파일)으로 다시 남기면 앞의 것이 바뀐다. 더 쓰지 않을 증거는 `job.py drop "<완료 기준>"` 으로 그 기준의 증거를 모두 지우고 다시 붙인다.
- 기록을 볼 때는 `job.py show`(기준마다 한 줄)나 `job.py check` 를 쓴다. 명령 전문과 로그까지 나오는 `job.py show --full` 은 PR 본문과 PR 댓글에 붙일 때만 돌린다.
- 경우마다: 계획서에 적은 경우(정상, 경계, 실패, 빈 값 등)마다 하나씩 남긴다.
- 화면이 있는 작업은 경우마다 스크린샷을 찍어 `job.py evidence "<완료 기준>" <절대 경로>...` 로 붙인다.
- 비밀 값은 `<REDACTED>` 로 가린다.
