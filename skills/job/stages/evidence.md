# 증거

완료 기준마다 실제 값을 남긴다. "통과했다"는 말이 아니라 값이다.

- 로그: `job.py log "<완료 기준>" "<명령>"` 은 명령을 돌려 출력 전체를 파일로 남기고 기준에 붙인다(화면에는 끝 40줄만 보인다). 출력에 기대값과 실제값이 둘 다 보이게 명령을 짠다.
- 고친 뒤 증거를 다시 남길 때는 `job.py drop "<완료 기준>"` 으로 앞의 증거를 지우고 붙인다.
- 경우마다: 계획서에 적은 경우(정상, 경계, 실패, 빈 값 등)마다 하나씩 남긴다.
- 화면이 있는 작업은 경우마다 스크린샷을 찍어 `job.py evidence "<완료 기준>" <절대 경로>...` 로 붙인다.
- 비밀 값은 `<REDACTED>` 로 가린다.
