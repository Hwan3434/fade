# 코드 리뷰

PR 을 열기 전에 이 브랜치의 변경을 리뷰한다.

1. `code-review` 스킬을 수준을 적어서 부른다(`medium`). 수준을 빼면 지난번에 쓴 수준으로 돈다. 첫 리뷰는 base 와의 전체 변경을, 다시 하는 리뷰는 앞 리뷰 뒤에 고친 부분을 본다.
2. 진짜 문제만 고친다. 고칠 때마다 그 문제를 잡는 테스트를 먼저 더해 `red` 를 보고 고친 뒤 `green` 을 돈다.
3. 고쳤으면 증거와 직접 써 보기를 마지막 커밋에서 다시 하고, 고친 부분을 다시 리뷰한다.
4. 리뷰할 때마다 `job.py review <남은 지적 수> "<요약>"` 으로 남긴다. 고치지 않기로 한 지적(오탐, 범위 밖)은 이유를 요약에 적고 수에서 뺀다.
5. 남은 지적이 0 이 되면 PR 단계로 간다. 같은 지적을 두 번 고쳐도 남으면 해결하지 못한 것이니 `job.py stop` 으로 남기고 끝낸다.
